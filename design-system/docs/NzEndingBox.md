맺음 박스 — 문서 끝의 연한 레몬(#FFF7DC) 박스. 손글씨 맺음 문구(#8A6D00 19px) + 레몬 pill CTA 버튼. 가운데 정렬, radius 10px, 위 여백 36px.

## 언제 쓰나
시트 본문의 마지막 블록. 레몬색이 넓은 면적으로 쓰이는 유일한 자리이므로 페이지당 하나만. 자체 스코프 포함.

## Props
- `lead` 맺음 문구 — 문자열 또는 배열(여러 줄, 6px 간격)
- `href` CTA 링크 (있으면 버튼) · `label` 버튼 라벨 (기본 "리뷰 구경하러 가기 →"(실제 사이트 문구), 14px 700)

## 규칙
문구는 손글씨 톤 1~2줄 ("다락방엔 리뷰가 더 있어요."). 버튼은 하나. 본문 중간에 쓰지 않는다.

## 예시
```tsx
<NzEndingBox lead={["여기까지 읽으셨다면 이미 반은 고른 거예요.", "나머지 반은 다락방에서."]} href="/" label="리뷰 목록 보러가기 →" />
```
