리드문 — 손글씨(OmyuPretty) 19px 회갈색 한두 문장. 아래 갈색(#C4B695) 2px 실선이 깔려 본문 진입을 알린다. 시트 본문의 첫 요소.

## 언제 쓰나
모든 문서형 페이지 제목 바로 아래. NzPaperSheet의 `lead` prop으로 쓰는 게 기본. 페이지당 하나.

## Props
- `children` 리드 문장. 1~2줄, 감성적인 톤("~했을 때 꺼내는 다섯 개.")

## 규칙
본문 폰트(IBM Plex)가 아니라 손글씨 폰트가 적용되는 자리다. 정보성 문장(가격·일정)은 본문에 쓰고, 리드문은 분위기를 연다.

## 예시
```tsx
<NzLead>퍼즐 좋아하는 친구가 "하나만 추천해줘" 했을 때 꺼내는 다섯 개.</NzLead>
```
